Space Mission Analytics Dashboard
🚀 Power BI Project | 4,324 Missions Analyzed | 90% Success Rate Insights

Project Overview
This interactive Power BI dashboard analyzes 60+ years of space mission data (1957-2020), tracking success rates, rocket performance, and global participation patterns across 44 countries and 48 companies.

Key Insights
✔ 90% average success rate across all missions
✔ Top-Performing Rockets:

Cosmos-3M (446 launches)

Voskhod (299 launches)
✔ Company Performance:

ULA leads with 99.29% success rate

NASA maintains 91.63% success
✔ 81.73% of rockets are now retired

Dashboard Features
Mission trends by year (peak: 119 missions in 1971)

Country/company performance comparisons

Rocket utilization and status tracking



Tools Used: Power BI (DAX, Power Query), Data Modeling
